# 采购报价分析助手 Agent

采购报价分析助手用于处理多家供应商的报价信息，统一不同报价口径，并根据采购需求中的固定规则进行合规性、成本、交付、付款和风险分析。

## 一、Agent 访问入口：
https://yujun2022.github.io/purchase-quote-agent/

## 二、使用说明

### 1. 输入采购需求

支持直接输入自然语言采购需求，例如：

> 采购40台仓库工业标签打印机，打印分辨率不低于300 dpi，必须支持有线网络，合同生效后15个工作日内完成交付安装，整机保修3年，提供安装调试和至少1场培训，付款方式优先选择验收后付款。

系统会从自然语言中识别并整理以下内容：

- 采购数量
- 产品名称或类型
- 技术规格
- 网络或接口要求
- 交付期限
- 保修期限
- 安装调试要求
- 培训要求
- 付款偏好

### 2. 输入供应商报价

支持以下方式提供供应商信息：

- 上传`.xlsx`格式的Excel文件

供应商表格的列顺序不要求固定。系统会根据字段名称识别供应商、适用数量、分辨率、网络、设备单价、运费、安装调试、强制服务费、培训、交付周期、整机保修和付款方式等信息。

如果报价信息存在空值或无法识别的内容，系统不会自行猜测，而是明确列出具体供应商和具体字段，例如：

> 澄海的分辨率未提供。

当前Agent主要支持文字和Excel输入。图片、PDF暂不作为直接分析输入；如报价来自图片或PDF，可先转换为Excel后提交。

## 三、规则使用说明

Agent不会仅凭通用常识自由判断，而是按照“采购需求规则 + 供应商报价数据 + 固定分析规则”进行分析。

### 1. 采购规则结构化

系统首先将自然语言采购需求转换为结构化规则，包括：

- 数量规则
- 技术规格规则
- 网络或接口规则
- 交付规则
- 保修规则
- 安装调试规则
- 培训规则
- 付款偏好规则

### 2. 报价信息标准化

系统将不同供应商的文字、表格或Excel报价转换为统一字段，包括：

- 供应商名称
- 适用数量
- 分辨率
- 网络类型
- 设备单价
- 运费
- 安装调试费
- 强制服务费
- 培训情况
- 交付周期
- 整机保修期限
- 付款方式

### 3. 固定规则核验

系统按照以下优先级执行判断：

1. 硬性技术规格
2. 硬性交付和保修要求
3. 必须提供的安装和培训服务
4. 总成本比较
5. 付款条件等商务偏好
6. 风险和推荐排序

其中：

- 硬性规格不满足时，判定为不合规或高风险。
- 交付期限不满足时，判定为交付不合规。
- 保修年限不足时，判定为保修不合规。
- 安装、培训等必需服务缺失时，列入风险或待确认事项。
- 运费、安装费和强制服务费会纳入总成本计算。
- “已包含”“免费”等明确报价内容按实际数据处理，不额外虚构费用。
- 空值、无法识别或表述不清的内容标记为“待确认”。

如果供应商价格较低但不满足硬性要求，Agent不会因为价格低而直接推荐该供应商。

## 四、输出格式说明

分析完成后，Agent会按照统一结构输出结果。

### 1. 采购需求摘要

展示系统识别出的采购数量、产品类型、规格要求、交付要求、保修要求、安装调试要求、培训要求和付款偏好。

### 2. 供应商标准化报价表

统一展示各供应商的：

- 设备总价
- 运费
- 安装调试费
- 强制服务费
- 其他已识别费用
- 总成本
- 交付周期
- 保修年限
- 付款方式
- 培训情况

### 3. 合规性判断

逐家供应商输出：

- 是否合规
- 合规项
- 不合规项
- 具体问题
- 对应采购规则

示例：

> 北川：不合规。分辨率为203 dpi，不满足“打印分辨率≥300 dpi”的硬性规格要求。

### 4. 成本分析

包括设备总价、运输费用、安装调试费、强制服务费、总成本，以及未计入或无法确认的费用。

总成本原则上按照以下公式计算：

```text
总成本 = 设备单价 × 采购数量 + 运费 + 安装调试费 + 强制服务费 + 已明确的其他必需费用
```

### 5. 交付与付款分析

分别展示：

- 交付周期
- 是否满足交付期限
- 是否包含送达和安装
- 付款方式
- 是否符合“验收后付款优先”的商务偏好

### 6. 隐性费用

识别可能影响最终采购成本的费用或信息缺口，例如：

- 运费未说明
- 安装调试费用未说明
- 强制服务费未说明
- 培训费用未说明
- 税费是否包含不明确
- 现场服务费未说明
- 超期交付可能产生的额外成本

### 7. 风险等级

风险等级分为：

- **高风险**：不满足硬性规格、交付或保修要求。
- **中风险**：关键费用、服务或商务条件未明确。
- **低风险**：满足采购要求，仅存在轻微商务差异或待确认事项。

### 8. 待确认事项

系统会具体指出待确认对象和字段，不会只列出供应商名称。

示例：

- 澄海的分辨率未提供。
- 青岳的培训是否包含现场培训未说明。
- 远屿的运费是否已包含在设备报价中不明确。
- 星拓是否支持仓库现有有线网络环境需要确认。

### 9. 推荐方案

输出推荐供应商、推荐等级、是否满足硬性要求、总成本、交付能力、付款条件和主要风险。

### 10. 推荐理由

推荐理由必须基于实际报价数据和采购规则生成，通常包括：

- 是否满足全部硬性要求
- 总成本是否具有优势
- 交付周期是否满足要求
- 保修期是否满足要求
- 安装和培训是否完整
- 付款条件是否有利
- 是否存在重大待确认事项或履约风险

如果没有供应商完全满足要求，Agent会明确说明当前不存在完全合规方案，并列出最接近方案及需要整改或谈判的具体问题。

## 五、典型分析结果示例

```text
推荐供应商：青岳

推荐理由：
1. 分辨率、网络、数量、交付和保修均满足采购硬性要求。
2. 已提供安装调试和远程培训服务。
3. 付款方式为验收后30天，符合验收后付款优先的商务偏好。
4. 总成本已包含设备、运费和安装调试费用。

主要风险：
- 需要确认远程培训是否满足实际使用部门的培训要求。
```
